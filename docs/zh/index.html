这些结果不能说明什么

基准分数只反映模型在这套规则下的表现，不应被外推成更宽泛的能力结论。

查看规则与方法 →
缺陷是合成的

植入缺陷是可精确评分的受控任务，不代表现实中的所有模型故障。

不等于“原生读懂权重”

高分说明模型能有效完成“找方向 → 改权重 → 验证”的实验闭环。

成本也是结果

预算上限一致，但供应商定价、Token 口径和默认推理模式仍会影响成本。
