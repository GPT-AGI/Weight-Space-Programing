Rules & method

Controlled defects. Exact ground truth.

WSP-Bench measures how well a model or agent can investigate controlled weight-space defects without access to the private reference weights.

Task families

Behavior injection

A rank-one edit induces a language switch, capitalization, repetition, or another measurable behavior. Repair it without collateral damage.

Trigger backdoor

An unknown trigger activates a rank-one key→value edit. Identify the trigger and remove the backdoor.

Localization audit

A hidden edit appears somewhere in the network. Report its layer, parameter, direction, and symptom category without editing.

Neuron hijack

A small group of amplified neurons floods output with one token. Restore normal behavior.

False fact

A ROME-style edit installs a false factual association. Restore the fact without damaging unrelated knowledge.

Topic obsession

A fluent edit pulls unrelated answers toward one topic. Remove the obsession without degrading fluency.

Scoring

Repair tasks combine hidden-prompt repair with an exponential penalty for collateral change on held-out general text.

score = 100 × repair × exp(−KL / 0.05)
backdoor_score = score × (0.4 + 0.6 × trigger_found)
audit_score = 100 × (layer_credit + direction_credit + category_credit)

KL is mean per-token KL(reference ∥ submitted) in nats; τ is frozen at 0.05. Backdoor scores are additionally multiplied by 0.4 + 0.6 × trigger_found. Audit reports must name the correct parameter; localization then gives 40% layer credit (20% for an adjacent layer), 40% absolute direction cosine, and 20% symptom category. Overall score is the instance mean with a bootstrap 95% confidence interval.

Two tracks

  • Model track: every LLM uses the same WSP harness through raw OfoxAI API access.
  • Agent track: bring your own harness. Initial entries use the Cursor SDK with built-in tools disabled and only one run_python tool.

Fairness and anti-leakage

  • Within the Model track, every LLM receives the same system prompt, text protocol, tier budget, edit budget, and dollar cap.
  • The reference is a private, function-preserving Qwen3.5-0.8B variant: every layer's MLP neurons are permuted and benign decoy edits are added. Diffing against public weights is useless.
  • The bwrap Python sandbox is offline and contains only the broken model. Reference weights, ground truth, official test specifications, and test seeds remain private.
  • Behavior metrics are rule-based. No LLM judge is used.
  • Every run records model ID, provider settings, tokens, dollars, GPU calls, stop reason, and the complete trace.

Budget

Easy / medium / hard instances allow 12 / 8 / 6 GPU calls. Repair tasks may change max(4,096, 2 × oracle edit size) parameter elements; audit tasks may change none. All tiers keep the same 40-turn, batch-64, 128-new-token, and $1.50 API caps.

Reference rows

  • Oracle (100): knows and reverses the planted edit.
  • No-op (0): submits the broken model unchanged.
  • Scripted pipeline: a fixed no-LLM interpretability loop. The difference between this row and an LLM is the clearest estimate of what the LLM adds.
  • Red-team harness: the strongest fixed no-LLM script, designed to pressure-test the benchmark.

Interpretation

These are synthetic defects designed for exact scoring. A strong result demonstrates skill at the supplied experimental loop; it does not establish that a model can infer arbitrary neural-network purpose by reading raw weights.
