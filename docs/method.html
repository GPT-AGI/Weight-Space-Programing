Rules & method

One harness. Exact ground truth.

WSP-Bench measures how well an LLM can investigate and repair controlled weight-space defects without access to the clean checkpoint.

Task families

Behavior injection

A rank-one edit induces a language switch, capitalization, repetition, or another measurable behavior. Repair it without collateral damage.

Trigger backdoor

An unknown trigger activates a rank-one key→value edit. Identify the trigger and remove the backdoor.

Localization audit

A hidden edit appears somewhere in the network. Report the layer, parameter, and direction without editing.

Neuron hijack

A small group of amplified neurons floods output with one token. Restore normal behavior.

Scoring

For edit tasks, repair is measured on hidden prompts and discounted by collateral change on held-out general text. Values are clipped to their stated ranges.

repair = clip((bug_rate(broken) − bug_rate(submitted)) / (bug_rate(broken) − bug_rate(clean)), 0, 1)
instance_score = 100 × repair × (1 − collateral_penalty)

Collateral penalty is derived from mean per-token KL(clean ∥ submitted) between frozen free and maximum thresholds. Audit tasks use 100 × localization, combining layer/parameter identification and absolute cosine similarity to the planted direction. Overall score is the mean of instance scores, with a bootstrap 95% confidence interval over instances.

Fairness and anti-leakage

  • Every model receives the same system prompt, text protocol, turn limit, GPU-call limit, edit budget, and dollar cap.
  • The Python sandbox has no network and contains only the broken model. The clean checkpoint and ground truth remain in the scoring process.
  • Defect direction, strength, layer, and trigger are randomized. Official test specifications and seeds remain private.
  • Behavior metrics are rule-based. No LLM judge is used.
  • Every run records model ID, provider settings, tokens, dollars, GPU calls, stop reason, and the complete trace.

Budget

Each v0.1 instance allows at most 40 turns, 20 GPU calls, batches of 64, generations of 128 new tokens, 262,144 changed parameters, and $1.50 in model API cost. Reaching a limit stops the episode and scores the current submission.

Reference rows

  • Oracle (100): knows and reverses the planted edit.
  • No-op (0): submits the broken model unchanged.
  • Scripted pipeline: a fixed no-LLM interpretability loop. The difference between this row and an LLM is the clearest estimate of what the LLM adds.

Interpretation

These are synthetic defects designed for exact scoring. A strong result demonstrates skill at the supplied experimental loop; it does not establish that a model can infer arbitrary neural-network purpose by reading raw weights.
